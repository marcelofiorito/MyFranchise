Solution Overview 01 / 06
"What is RunMyFranchise?"
So what we're looking at here is RunMyFranchise — basically an AI assistant for franchise store owners, all running on SAP Business AI Platform. The idea is simple: instead of digging through dashboards, the franchisee just asks Joule in plain language. What's running out? What should I reorder? And the system pulls from inventory, demand forecasts, NPS — everything — and gives you a straight answer.

The AI Layer 02 / 06
"How does Joule know what tools to call?"
Joule consumes tools via MCP servers — in production, those servers sit behind the Integration Suite MCP Gateway, which handles auth, rate limiting and auditing. For this demo, no tenant was available for that, so we built the MCP server in Node.js running on Business AI Platform Cloud Foundry, exposed in a way that Joule Studio, classic edition could consume directly — same result, different path.

BDC Knowledge Graph 03 / 06
"How does Joule give such precise, context-aware answers?"
Actually, this solution already runs on SAP Business Data Cloud — HANA Cloud, Datasphere, and SAC are all BDC components. What's not available yet is the Knowledge Graph. When it is, Joule will be able to understand business semantics — how products relate to categories, how stores connect to regions, what a stockout actually costs in context. That richer layer will make every AI answer even more precise and business-aware.

Data Foundation 04 / 06
"Where does all the franchise data live?"
All the data Joule just read — inventory levels, demand forecasts, NPS scores — that all lives in a custom schema on SAP HANA Cloud. It's an in-memory cloud database, and we're using it as the operational backbone for the entire franchise network. The MCP server talks to it directly, no extra layers. And SAP Analytics Cloud is connected live to that same schema, so the franchisor sees the exact same numbers in their executive dashboards.
HANA Cloud Custom Schema SAC Live
S/4HANA Integration 05 / 06
"What happens when Joule creates a replenishment order?"
When Joule creates a replenishment order, the ideal path would post a real Purchase Order to S/4HANA for Retail via OData — triggering warehouse picking, logistics scheduling, and delivery confirmation. For this demo, we're simulating that step: the order is recorded locally and the franchisee gets a reference number in the chat. In future releases, with access to an S/4HANA for Retail tenant, this becomes a real end-to-end supply chain execution.

Full Architecture 06 / 06
To be clear about what's actually running here: Joule Agents + MCP Servers + HANA Cloud — that's the real stack. And since HANA Cloud, Datasphere and SAC are all part of SAP Business Data Cloud, we're already inside that ecosystem. What's still ahead: S/4HANA events flowing via Advanced Event Mesh for real-time supply chain reactions, the BDC Knowledge Graph for richer business semantics, and SAP AI Core with the RPT foundation model for demand predictions and financial forecasts — AI-driven, not just historical.
