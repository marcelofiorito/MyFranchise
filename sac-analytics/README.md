# MyFranchise SAC Analytics

Projeto HDI separado com Calculation Views tipo CUBE para SAP Analytics Cloud.

## Setup
Ver `docs/infraestrutura/sac-setup.md` no projeto principal.

## Como criar as Calculation Views
1. Abrir este projeto no BAS
2. Command Palette → Create SAP HANA Database Artifact
3. Path: `db/src` | Type: Calculation View | Data Category: CUBE
4. Configurar datasources no editor gráfico
